### Goal
Every paper position is force-closed by EOD even when only `run_bridge()` runs (no separate
orchestrator). EOD square-off must be a first-class, testable code path — not a cron afterthought.

### Context / why
`run_bridge()` gates EOD on the **real wall clock** (`now_str() >= MARKET_CLOSE`), so the
square-off branch is untestable in the sim without a clock injection. PORCUPINE_STATE §7
explicitly lists this as the remaining lifecycle gap: *"EOD square-off branch (needs a clock
injection — `run_bridge` gates on real `now_str()>=15:30`)."* Memory
`entry_path_and_stale_trade_blocker`: run_bridge had no EOD square-off; a stale cron was bolted on.
